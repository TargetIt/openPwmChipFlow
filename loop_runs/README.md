# Loop Runs

This directory stores execution records produced with the OpenChipAgentPlatform Loop/Harness style.

Each run should answer four questions:

1. What goal was attempted?
2. What tools and project state were observed before acting?
3. Which stages passed, failed, were skipped, or need tooling?
4. Which artifacts are trustworthy evidence, and which are stale or incomplete?

Skipped required stages must not be reported as full-flow success.
