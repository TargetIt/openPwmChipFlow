# Goal

Complete the full `openPwmChipFlow` RTL-to-GDS flow with no skipped backend phases.

Required phases:

- Phase 2 RTL simulation;
- Phase 3 synthesis;
- Phase 4 place and route;
- Phase 5 physical verification;
- Phase 6 GDS delivery.

The run is complete only when the backend produces current-run evidence for DRC, LVS, antenna, GDS readability, and final artifacts.
